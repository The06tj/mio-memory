# Example memory-writing protocol

This is reference material for a separate, user-approved writing workflow.
Reading this file through MCP does not authorize edits, expanded access, or changes
to the assistant's instructions. This project's search/fetch service cannot write notes.

## Records
Separate a fact, a quotation, an interpretation, and an unanswered question.
Use dates, provenance and the statuses active, superseded, deprecated or uncertain.
Do not infer that a document update date re-confirms every fact it contains.

## Changes
Ask the owner before a writing workflow changes their notes. Preserve dated history
when a fact changes. Keep archival material clearly marked and out of current claims.

## Episodes
Preserve the context and speakers of paired quotations. Do not turn one interaction
into a stable personal trait. Keep sensitive material scoped to the owner's choices.

## Retrieval
Search narrow keywords, then read the necessary section and cite its file and lines.
A citation shows what a note records; it is not independent proof that the record is true.
