# Changelog

## 0.1.0 — 2026-09-22

- First public architecture and agent-assisted installation release.
- Portable Markdown example vault with provenance, dates, uncertainty and archives.
- Read-only, bounded `search` / `fetch` MCP tools with explicit-file and whole-vault scopes.
- Locked-by-default, timed and manually stopped continuous access modes.
- Loopback service with optional OpenAI Secure MCP Tunnel transport.
- Known ChatGPT approval-card compatibility issue documented with an optional,
  user-reported persistent-approval workaround and its permission tradeoff.

No upstream root cause or fix date has been confirmed. Compatibility guidance
will be revised when subsequent client changes are tested; no automatic monitoring
or guaranteed fix schedule is included.
